# Starter Template: `agent-saas-cockpit` (Combo 10)

Production React 19 + TypeScript + Tailwind v4 AI Agent & SaaS workspace built on the **`obsidian-precision`** OKLCH preset.

## Included Architecture
- **3-Zone Spatial Ergonomics**: Collapsible Navigation Rail (`[` shortcut) + Streaming Tool-Execution Thread + Contextual Telemetry Sidecar.
- **Human-in-the-Loop Gate**: Interactive migration approval card that updates live cluster P99 metrics and SVG sparklines.
- **Universal Command Palette**: Press `Cmd+K` / `Ctrl+K` anywhere.

## Run Locally
```bash
npm install
npm run dev
```
