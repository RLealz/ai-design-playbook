# Starter Template: `editorial-deck-diagram` (Combo 7)

Zero-dependency HTML/SVG Executive Slide Deck (`deck.html`) + Orthogonal System Architecture Blueprint (`architecture-diagram.html`) built on the **`industrial-blueprint`** preset.

## Features
- **`deck.html`**: 12-column `16:9` slide grid, conclusion-first headlines, `tabular-nums` KPI callouts, `←`/`→` navigation, `T` Dark/Light toggle, and lossless `@media print` PDF export (`Ctrl+P`).
- **`architecture-diagram.html`**: Semantic lane colors (Cyan Ingress, Indigo Compute, Emerald Persistence, Amber External), `8px` rounded orthogonal elbows, and animated `<animateMotion>` data pulses—zero Mermaid slop.
