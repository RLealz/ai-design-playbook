# Starter Template: `anti-slop-landing` (Combo 1)

Zero-build, high-craft asymmetric landing page scaffold built on the **`swiss-editorial`** OKLCH token preset.

## Anti-Slop Guarantees Built In
- **Structural Contrast (`hallmark`)**: 4 distinct consecutive section mechanics (Asymmetric Split Hero with live interactive simulator → 7/5 Concentric Bento with animated orthogonal SVG trace → Sticky Two-Column Benchmark Comparison → Letterpress CTA Lockup).
- **Concentric Geometry (`make-interfaces-feel-better`)**: `--radius-outer = calc(var(--radius-inner) + var(--pad-bento))`.
- **Tabular Telemetry**: `font-variant-numeric: tabular-nums` on every counter, benchmark, and SVG callout.
- **Accessibility**: Responsive mobile stack (`< 920px`) + `prefers-reduced-motion` support.
