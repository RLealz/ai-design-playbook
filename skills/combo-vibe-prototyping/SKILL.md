# ⚡ Combo 4: Rapid Multi-Direction "Vibe Prototyping" (v2.0)

* **Preset Switching**: Swap instantly across any of the 6 built-in `presets/` (`swiss-editorial`, `obsidian-precision`, `tactile-daylight-bento`, `industrial-blueprint`, `atmospheric-cinema`, `kinetic-neo-brutalist`).

## 4-Phase Execution Pipeline

### Phase 1: Spin Up 3 Orthogonal Structural Directions
Never output 3 color swaps of the same wireframe. Vary **grid, density, typography, and interaction model**:
1. **Direction A — `swiss-editorial`**: Warm paper (`#FAF8F5`), exposed `1px` hairlines, `Instrument Serif` + `Plus Jakarta Sans`, asymmetric editorial split.
2. **Direction B — `obsidian-precision`**: `#090A0F` canvas, `1px` top specular highlights, `Cmd+K` command-first chrome, `JetBrains Mono` `tabular-nums`.
3. **Direction C — `tactile-daylight-bento` (or `kinetic-neo-brutalist`)**: Physical elevated bento cards, spring-loaded micro-controls, bold `Cabinet Grotesk` / `Syne` display type.

### Phase 2: Pull Curated Component Primitives (`superdesign-skill`)
Pull proven interaction patterns rather than generic Tailwind boxes:
* `21st.dev` / `Shadcn Space` for structural blocks; `React Bits` / `Skiper UI` for dynamic islands, text reveals & cursors; `Vengeance UI` / `Pacifio UI` for specular dark surfaces; `Motion Primitives` for spring dialogs & tabs.

### Phase 3: Craft & Feel Enforcement (`ui-skills` + `make-interfaces-feel-better`)
* Concentric border radii (`outer = inner + padding`), `tabular-nums` on all numbers, spring physics (`stiffness: 300, damping: 24`), and full interactive states (`hover`, `focus-visible`, `active scale(0.98)`, `disabled`, `loading`).

### Phase 4: Winning Direction Lock (`impeccable` + `unslop`)
* Run `colorize`, `typeset`, and `polish` on the user's chosen direction, export its locked `DESIGN.md`, and verify APCA contrast via `unslop`.
