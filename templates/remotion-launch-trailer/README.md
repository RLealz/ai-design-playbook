# Starter Template: `remotion-launch-trailer` (Combo 5)

60fps Dual-Aspect (`1920×1080` Landscape + `1080×1920` Vertical Reel) Remotion 4 product launch trailer pre-built with the **45-second (`2700` frame) 5-Act Beat Sheet** and **`motionmaxxing` rules**.

## Quick Start
```bash
npm install
npm run studio
npm run render:16x9
pwsh ./scripts/master-ffmpeg.ps1
```
