# Starter Pack: `discovery-audit-pack` (Combo 0 — Pre-Design Phase)

Pre-design discovery, live-website diagnostic, and brand fact-lock kit. Run **before** starting any Combo 1–14 implementation so redesigns and new products build strictly on verified facts, preserved brand marks, and clean SEO/URL plans.

## Included Files
- **`scripts/audit-live-surface.mjs`**: Playwright pre-design crawler capturing `1440px` & `390px` baseline screenshots, `<h1>`/meta/OG/CMS generator inventory, `390px` overflow measurements, and unedited template/placeholder warnings into `evidence/surface-inventory.json`.
- **`brand-facts.json`**: Separates `verifiedFacts` & `officialLogoPath` from `unconfirmedItemsRequiringHonestEmptyState`.
- **`legacy-redirects.json`**: Maps legacy public URLs to `301-redirect` or `retire-410` decisions prior to domain cutover.
- **`AUDIT-BRIEF.md`**: Diagnostic severity table + `R1–R8` acceptance contract.
