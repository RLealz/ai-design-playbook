# Starter Template: `interactive-cutaway` (Combo 3 / Combo 9 / Combo 11)

Zero-build Interactive 3D Exploded-View Hardware Cutaway + Dimensional Blueprint HUD built with Three.js ImportMap and the **`industrial-blueprint`** aesthetic.

## Features
- **Axial Explosion Scrubbing**: Real-time damped slider (`0%–100%`) separating 5 coaxial PBR + glass sub-assemblies.
- **Per-Part Isolation**: Click any component in the spec rail to ghost non-selected layers (`opacity: 0.18`) and inspect tolerances in the live HUD.
- **GPU Discipline**: 3-point studio lighting, `devicePixelRatio` clamped to `2`, and `IntersectionObserver` loop sleep.
